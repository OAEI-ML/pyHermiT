# WPR3 native datatype component-solver evidence

The native component solver uses the same deterministic equality collapse, exact
finite/complement-domain intersections, fixed-value checks, cardinality checks,
inequality-core elimination, minimum-remaining-values search, and sufficient clash
dependency policy as the pure-Python semantic oracle.

## Shared differential

The fixture at tests/data/datatypes/wpr3-native-solver-v1.json is generated by
tools/datatypes/build_native_solver_fixture.py with seed 0x57A32026.
It contains 13 canonical semantic literals and 366 components:

- crafted coverage for every stable clash kind, lexical aliases, duplicate-edge
  dependency selection, finite graph colouring, unbounded complements, and the
  reduced active-clash core;
- 256 deterministic finite components, each checked by the Python optimized and
  exhaustive solvers before serialization; and
- 96 deterministic complement/mixed components checked by the optimized symbolic
  Python solver.

The Rust test decodes the same literal payloads, reconstructs every component, and
compares SAT/UNSAT, clash kind, exact dependency levels, and clash variables. SAT
certificates are additionally checked against domains, fixed values, equalities, and
inequalities. Regeneration is tested on Python 3.10 and 3.12.

## Safety and resource behavior

The solver validates sorted unique variables and all references before allocation-heavy
work. Variable, constraint, and step limits are checked; arithmetic is checked or
saturating only where saturation conservatively forces a resource/error path.
Cancellation is polled initially and through preparation, elimination, and search.
Tests prove cancellation and resource exhaustion return errors without a partial result.
The crate forbids unsafe code and strict all-target Clippy passes.

## Local performance sample

Command:

    PYO3_PYTHON=/usr/local/bin/python3.12 cargo bench \
      --manifest-path native/Cargo.toml --no-default-features \
      --bench datatype_kernel -- --quick

Host-local Criterion intervals (2026-07-17):

| Workload | Time interval |
|---|---:|
| eliminated three-colour chain, 32 variables | 137.08–137.36 µs |
| eliminated three-colour chain, 128 variables | 533.59–562.98 µs |
| eliminated three-colour chain, 512 variables | 2.3757–2.5736 ms |
| equality collapse, 1,024 variables | 1.1612–1.2170 ms |
| unsatisfiable two-colour triangle | 21.977–22.968 µs |

These are development-host observations, not portable release thresholds. The chain
results demonstrate that the sound degree/cardinality elimination avoids exponential
colour search on the common sparse case.
