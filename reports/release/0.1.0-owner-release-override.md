# pyHermiT 0.1.0 owner release override

Date: 2026-07-30

The repository owner explicitly authorizes the `0.1.0` production release and accepts
the remaining external release risks recorded in `reports/release-report-local.json`.
This override closes the repository release gates for this version as follows:

- `LIC-001` is **waived as-is** for this release. The waiver is an owner release
  decision, not legal advice, not an owner/legal-review signoff, and not a
  representation that legal review occurred. The LGPL-3.0-or-later project decision,
  provenance inventory, notices, corresponding-source policy, and completed repository
  audits remain unchanged.
- The unavailable licensed W3C body run, larger Java differential sample, complete
  hosted native-wheel matrix, and dedicated performance calibration are accepted as
  post-release follow-up work. Existing local semantic, packaging, and provenance
  evidence remains the qualification basis for `0.1.0`.
- Local upload with the owner's PyPI account token is authorized because the coordinated
  consumer packages cannot resolve `pyowl-core` from PyPI until the core release exists.

This record applies only to `pyHermiT 0.1.0`. It does not waive future release gates,
change the project license, certify unbuilt native targets, or convert historical
development artifacts into production artifacts.
