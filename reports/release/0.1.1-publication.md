## Publication scope

The `0.1.1` PyPI release is deliberately **universal-only**: it publishes the
`py3-none-any` wheel and sdist above. No native, ABI3, or platform-specific wheel was
published for this version, and this record makes no native-artifact publication claim.
The repository's separately recorded native-backend tests remain implementation evidence,
not evidence that a native wheel is available from PyPI.

This verification record post-dates the immutable tag and published archives. It records
their externally observable identities and checks; it does not modify the tagged source,
retroactively place this file inside the published sdist, or broaden the version-scoped
owner authorization in `0.1.1-owner-release-override.md`.
