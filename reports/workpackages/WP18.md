## Outcome

The private encoded compiler now maps the retained pyowl-core schema into canonical
pyHermiT symbol, provenance, role, clause, and named-ABox fragments without paging the
same roots into Python objects. The implemented literal boundary preserves separate
source-literal spellings while deduplicating semantic values across every scalar-supported
literal family. Positive and negative data-property assertions, segmented composite
remapping, annotations, signed zero, lexical aliases, arbitrary-size numbers, binary
values, URI spelling, date/time offsets, and canonical XML fragments have exact
scalar/compiler manifest tests. The individual domain now also owns canonical anonymous
individuals used by OWL 2 DL-positive class, object-property, and data-property assertions,
including composite scope rebasing without misclassifying them as named individuals. Atomic
`ObjectComplementOf` assertions, subclass literals, equivalence/disjointness members,
property domain/range constraints, and key classes over named classes now retain their
canonical expression symbol, sparse entity signature, negated-concept predicate/fact,
signed clauses, and builtin totality/clash clauses.
Atomic `DataOneOf`, `DatatypeRestriction`, and `DataComplementOf` property ranges and
datatype-definition right-hand sides now receive the corresponding canonical data-range
expression symbols, signed predicates, data-sort totality/clash clauses, provenance, and
composite identifier remapping.
Flat multi-live `DataIntersectionOf` and `DataUnionOf` property ranges now receive the
scalar-identical positive generated datatype entity and data-range symbol when all operands are
supported stable data literals. Their typed definition clauses, source range clauses, annotated
definition reuse, source-entity reindexing, and composite remapping use the ontology's global
logical fingerprint namespace and match the scalar manifest exactly. Partially unsupported
data-Boolean operands still defer as one root without generated-symbol leakage.
Outer complement chains around otherwise supported flat data Booleans normalize by parity and
De Morgan duality before symbol construction and clausification.
Nested homogeneous data intersections or unions now flatten recursively through those complement
rules, preserving the scalar n-ary canonical identity for property ranges and datatype definitions.
Mixed nested data Booleans in `DataPropertyRange` now recursively atomize inner expressions and
publish the same dependency-ordered generated datatype definitions as the scalar normalizer.
Flat multi-live data intersections and unions on the right-hand side of `DatatypeDefinition`
compile directly to the scalar equivalence clauses without manufacturing a generated datatype.
Their source Boolean symbols, signed operands, provenance grouping, and composite remapping also
match scalar output exactly.
Named-individual `ObjectOneOf` class literals and their complements now receive canonical nominal
predicates, equality/inequality definitions, signed clauses or facts, and composite identifier
remapping across assertions, subclass/equivalence/disjointness axioms, property constraints, and
keys. Arbitrarily nested class and data complements over every supported atomic base reduce by
parity under the canonical depth and work budgets; unsupported complex or anonymous bases remain
deferred atomically.
Class and data intersections/unions that scalar normalization reduces to one supported atomic
literal now collapse natively through identity, absorbing, complement-parity, and duplicate rules.
This includes exact normalized disjoint-member ordering and forced-empty handling when distinct
source members collapse to the same class literal, plus composite identifier remapping.

scalar normalization reduces to `owl:Thing` or `owl:Nothing` now collapse to those same builtin
literals. The reduction is bounded and recursively composes with supported complement and Boolean
normalization. It publishes only after validating every operand, including those after an absorbing
top/bottom member, and when every discarded nonbuiltin entity is explicitly retained and the

root remains deferred. Explicitly declared bottom object/data properties retain their scalar symbol
identity while reducible quantifier, value, and cardinality forms still collapse exactly.

emit the exact definition edges and normalized disjoint consequences without manufacturing a
generated definition symbol. Stable multi-live member unions now synthesize the scalar-canonical
`ObjectUnionOf` key and its positive generated definition, then emit the same definition edges and
disjoint guard as the scalar compiler. Annotated, cross-root, and composite uses reuse that identity;
recursive Boolean and supported object/data restriction members now receive their distinct
positive and negative inner definitions and generated data-range dependencies before the outer
union is rewritten. Direct and complemented restrictions, annotations, and composite slices reuse
the same scalar identities.

extension does not advertise `encoded-structural-compiler-v1`, and ordinary backend
negotiation cannot select this path.

IRI and emits exact scalar messages for property-kind punning, class/datatype punning, reserved
vocabulary use, builtin use under the wrong entity kind, and missing declarations. The builtin
tables cover every scalar-supported class, property, annotation-property, and datatype IRI.
Named individuals are exempt from missing declarations, and correctly typed builtins need no
explicit declaration. Because these findings are ontology-global rather than rooted in one axiom,
their manifest `constructor` and `provenance_sha256` fields are JSON `null`, matching the scalar
contract. Composite merge removes source-local global findings, deduplicates retained uses and
declarations, and recomputes the rules once, detecting cross-slice punning while allowing a
declaration in one slice to satisfy a use in another in either source order. Entity-use,
declaration, ownership, issue, message, and work limits fail before publication; collection and
group scans poll cancellation at bounded checkpoints.

Selected `DatatypeDefinition` roots retain their full canonical statement-order key, head IRI, and
the sorted named datatype references reached through intersections, unions, complements, and
restriction bases. `DataOneOf` contributes no definition dependency, matching scalar core-reference
collection. Literal nodes encountered in axioms or ontology annotations retain their datatype IRI.
The global pass first chooses the scalar statement-order winner among builtin redefinition and
duplicate-definition failures, then checks every datatype use against the implemented builtin map
or a retained definition, and finally performs bounded topological cycle detection over custom
definitions. As in scalar validation, custom-datatype and unsupported-datatype literal issues are
compiled independently after the semantic-model check, with exact dynamic messages, constructors,
and nullable provenance. Composite merge removes source-local datatype findings, deduplicates the
private definition/reference/literal facts, and recomputes the complete model so a definition,
dependency edge, or literal use in another selected slice is observed in either source order.
Definition, reference, literal, issue, ownership, and work limits fail closed; definition
traversal, grouping, use, dependency, topological, and literal loops poll cancellation.
The private binding carries the scalar `error` or `ignore_with_warning` policy into each source
phase and merge recomputation. Opaque warnings use warning severity and therefore do not make a
warning-only manifest nonconforming. Unknown atomic ranges and standalone literal payloads are
accepted only in warning mode; executable range literals, restriction bases, and definition
dependencies preserve their scalar error boundary. Unknown IRIs are canonicalized across slices,
and malformed policy values fail before semantic publication.

Selected role axioms additionally retain a private canonical object-role fact model. Simple
`SubObjectPropertyOf`, `EquivalentObjectProperties`, `InverseObjectProperties`, and
`SymmetricObjectProperty` axioms expand to inverse-paired inclusion edges. Property-chain
inclusions and `TransitiveObjectProperty` seed the named role and its inverse as non-simple;
`owl:topObjectProperty` and `owl:bottomObjectProperty` are implicit normalized seeds. Upward
reachability over the complete simple-inclusion graph then reproduces the scalar non-simple
component propagation.

Full property-chain and transitivity records retain their inverse-generated form, canonical axiom
SHA-256, and full statement-order key. Semantic duplicates keep the scalar last statement,
including annotated duplicates and duplicates that cross selected slices. Roles are ordered by
their exact canonical structural bytes before the simple graph is collapsed into deterministic
SCCs. The complex members then extend the quotient dependency graph, and a bounded breadth-first
search selects the lexicographically least shortest strict cycle. This emits exact
`RIA_INVERSE_RECURSION`, `RIA_NON_REGULAR_RECURSION`, and `RIA_DEPENDENCY_CYCLE` projections while
preserving legal left/right boundary recursion, transitivity, symmetric components, and the
top-object-property exception. Composite merge strips source-local regularity findings and
recomputes the graph from deduplicated global facts, so cycles assembled across slices match direct
validation in either source order. Complex-inclusion, dependency-edge, issue, ownership, and work
limits fail closed; role indexing, SCC, chain, dependency, and cycle loops poll cancellation.

The same traversal records every role occurrence that scalar requires to be simple:
`FunctionalObjectProperty`, `InverseFunctionalObjectProperty`,
`IrreflexiveObjectProperty`, `AsymmetricObjectProperty`, each
`DisjointObjectProperties` member, and nested `ObjectHasSelf`, `ObjectMinCardinality`,
`ObjectMaxCardinality`, or `ObjectExactCardinality` roles. A reachable non-simple role emits
`OWL2DL_NON_SIMPLE_PROPERTY` with the root axiom constructor and canonical axiom SHA-256.
Composite merge removes local findings, canonicalizes the private edges, seeds, and requirements,
and reruns closure, so a chain, transitivity declaration, or inclusion path in another selected
slice is observed in either source order. Separate inclusion, seed, requirement, issue, ownership,
and work limits fail closed; role/member, closure, and requirement loops poll cancellation.

Selected extension roots follow the same canonical path. Schema-1 SWRL roots emit the exact
`OWL2DL_EXTENSION_COMPONENT` rule, severity, message, constructor, and canonical provenance.
Canonical full-extension keys provide `extensions_checked` accounting and collapse duplicate
extensions across composite sources independently of slice order. Extension count, ownership, and
work limits fail before publication, and cancellation is polled before extension provenance is
constructed.

Ontology identity remains outside structural-columns schema 1 and instead crosses a private
side-context shaped as version `1` plus canonical rows of document key, optional ontology IRI, and
optional version IRI. The boundary requires exact tuples, an exact integer version, exact nonempty
UTF-8 strings, strictly increasing unique document keys, and an ontology IRI whenever a version IRI
is present. Both IRI fields reuse the encoded entity IRI grammar, including absolute scheme,
forbidden-codepoint, and percent-escape checks. Relative or malformed schemes, forbidden
characters, bad escapes, oversized contexts, and noncanonical rows return operational validation
errors without producing a manifest.

After direct profile compilation or composite merge, the context scan checks the RDF, RDFS, XSD,
and OWL namespaces and appends the exact scalar ontology/version rule, dynamic message, error
severity, and `OntologyID` constructor. Structural columns still supply no origin rows, so these
private issues intentionally keep `provenance_sha256` null and omit `document_keys`; identical
projected findings from multiple documents deduplicate canonically. Document count, owned bytes,
issue count, and work are charged to the existing phase limits. Decoding polls before the context,
once before each document copy, and after canonical validation; application separately polls each
document and IRI plus canonicalization and publication. A binding-level deterministic injector
interrupts each decode boundary with the existing reasoner error and verifies that every
production retry returns the original manifest bytes.

The phase is intentionally private and absent from capability metadata. Structural-columns v1
does not encode profile origin rows, so its manifest projects only `rule_id`, `severity`, `message`,
`constructor`, and `provenance_sha256`; it never invents `document_keys`. Full origin-bearing
public profile errors and permanent-session integration remain open.
Malformed encoded input and resource limits return validation errors, caller cancellation returns
the existing native interruption error with its original reason, and profile findings remain a
successful manifest.
