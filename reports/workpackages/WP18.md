# WP18 — native structural compiler checkpoint

Status: implementation in progress; capability remains fail-closed
Prepared: 2026-07-23
Evidence revision: `62eda29af77d8fda7ac547fbea43d2997f0ceb9b`
Capability claim: none

## Outcome

The private encoded compiler now maps the retained pyowl-core schema into canonical
pyHermiT symbol, provenance, role, clause, and named-ABox fragments without paging the
same roots into Python objects. The implemented literal boundary preserves separate
source-literal spellings while deduplicating semantic values across every scalar-supported
literal family. Positive and negative data-property assertions, segmented composite
remapping, annotations, signed zero, lexical aliases, arbitrary-size numbers, binary
values, URI spelling, date/time offsets, and canonical XML fragments have exact
scalar/compiler manifest tests. The individual domain now also owns canonical anonymous
individuals used by OWL 2 DL-positive class, object-property, and data-property assertions,
including composite scope rebasing without misclassifying them as named individuals. Atomic
`ObjectComplementOf` assertions, subclass literals, equivalence/disjointness members,
property domain/range constraints, and key classes over named classes now retain their
canonical expression symbol, sparse entity signature, negated-concept predicate/fact,
signed clauses, and builtin totality/clash clauses.
Atomic `DataOneOf`, `DatatypeRestriction`, and `DataComplementOf` property ranges and
datatype-definition right-hand sides now receive the corresponding canonical data-range
expression symbols, signed predicates, data-sort totality/clash clauses, provenance, and
composite identifier remapping.
Flat multi-live `DataIntersectionOf` and `DataUnionOf` property ranges now receive the
scalar-identical positive generated datatype entity and data-range symbol when all operands are
supported stable data literals. Their typed definition clauses, source range clauses, annotated
definition reuse, source-entity reindexing, and composite remapping use the ontology's global
logical fingerprint namespace and match the scalar manifest exactly. Partially unsupported
data-Boolean operands still defer as one root without generated-symbol leakage.
Outer complement chains around otherwise supported flat data Booleans normalize by parity and
De Morgan duality before symbol construction and clausification.
Nested homogeneous data intersections or unions now flatten recursively through those complement
rules, preserving the scalar n-ary canonical identity for property ranges and datatype definitions.
Mixed nested data Booleans in `DataPropertyRange` now recursively atomize inner expressions and
publish the same dependency-ordered generated datatype definitions as the scalar normalizer.
Flat multi-live data intersections and unions on the right-hand side of `DatatypeDefinition`
compile directly to the scalar equivalence clauses without manufacturing a generated datatype.
Their source Boolean symbols, signed operands, provenance grouping, and composite remapping also
match scalar output exactly.
Named-individual `ObjectOneOf` class literals and their complements now receive canonical nominal
predicates, equality/inequality definitions, signed clauses or facts, and composite identifier
remapping across assertions, subclass/equivalence/disjointness axioms, property constraints, and
keys. Arbitrarily nested class and data complements over every supported atomic base reduce by
parity under the canonical depth and work budgets; unsupported complex or anonymous bases remain
deferred atomically.
Class and data intersections/unions that scalar normalization reduces to one supported atomic
literal now collapse natively through identity, absorbing, complement-parity, and duplicate rules.
This includes exact normalized disjoint-member ordering and forced-empty handling when distinct
source members collapse to the same class literal, plus composite identifier remapping.
Object/data existential and universal restrictions and minimum/maximum/exact cardinalities that
scalar normalization reduces to `owl:Thing` or `owl:Nothing` now collapse to those same builtin
literals. The reduction is bounded and recursively composes with supported complement and Boolean
normalization. It publishes only after validating every operand, including those after an absorbing
top/bottom member, and when every discarded nonbuiltin entity is explicitly retained and the
expression contains no discarded literal or anonymous-individual identity; otherwise the complete
root remains deferred. Explicitly declared bottom object/data properties retain their scalar symbol
identity while reducible quantifier, value, and cardinality forms still collapse exactly.
`DisjointUnion` roots whose normalized member union reduces to one supported literal or a builtin
emit the exact definition edges and normalized disjoint consequences without manufacturing a
generated definition symbol. Stable multi-live member unions now synthesize the scalar-canonical
`ObjectUnionOf` key and its positive generated definition, then emit the same definition edges and
disjoint guard as the scalar compiler. Annotated, cross-root, and composite uses reuse that identity;
recursive Boolean members now receive their distinct positive and negative inner definitions before
the outer union is rewritten. Restriction-bearing members still defer as one root.
`ObjectIntersectionOf` and `ObjectUnionOf` expressions in either side of `SubClassOf`, as
members of `EquivalentClasses`, in `ClassAssertion`, as object/data property class constraints, or
as the class expression of `HasKey`, or as a `DisjointClasses` member now receive the
scalar-identical, polarity-specific generated class entity and expression symbols when all operands
are supported stable class literals. Their definition clauses, generated provenance, source
inclusions, equivalence cycles, assertion facts, role constraints, key clauses or disjoint guards,
annotated-definition reuse, entity reindexing, and composite remapping use the ontology's global
logical fingerprint namespace and match the scalar manifest exactly. Nested class Booleans now
normalize recursively to negation normal form, flatten homogeneous connectives, and atomize mixed
inner nodes into polarity-matched generated classes. The source and rewritten expression symbols,
inner/outer definition clauses, shared provenance, and composite reuse also match scalar output.
Direct, complemented, and Boolean-nested `ObjectHasSelf` expressions now share the same recursive
definition pipeline, including repeated-variable role clauses, inverse-role lookup, polarity
inversion through complements, generated `DisjointUnion` members, and composite reuse.
Object quantifiers now share that pipeline in all four definition directions. Negative
`ObjectSomeValuesFrom` definitions and positive `ObjectAllValuesFrom` definitions emit the exact
relational Horn clauses. Positive existentials emit scalar-compatible unary `AtLeastObject(1, R,
F)` predicates, while negative universals emit the dual `owl:Thing -> AtLeastObject(1, R, not F)
or G` clause. Outer complements apply NNF duality to the constructor and filler before atomization.
Fillers recursively atomize through supported class Booleans, self restrictions, and object
quantifiers. Recursive Boolean owners, inverse roles, signed nominal fillers, annotated duplicates,
and composite slices preserve scalar predicate identity, provenance, clause ordering, and
identifier remapping.

This is a component checkpoint, not a completed structural compiler. The native
extension does not advertise `encoded-structural-compiler-v1`, and ordinary backend
negotiation cannot select this path.

The literal checkpoint covers the string and Boolean families; the complete integer,
decimal, rational, float, and double map; hex/base64 binary values; `xsd:anyURI`;
`xsd:dateTime` and `xsd:dateTimeStamp`; and `rdf:XMLLiteral`. Numeric digits/exponents,
decoded binary bytes, XML nodes/depth, total work, and owned bytes are bounded before
semantic publication. XML processing rejects DTD/entity declarations and uses a pinned,
audited Rust parser while preserving the scalar C14N identity contract. `rdfs:Literal`
remains intentionally unavailable as a direct lexical datatype because the scalar
compiler defines it only as the universal data range.

Anonymous individual keys and displays apply each slice's inner-to-outer scope maps before
domain merging. Their identifiers receive the scalar `owl:Thing` fact, but stay outside the
named-individual signature, output set, predicate, and builtin facts. Anonymous operands in
negative assertions and identity axioms remain atomically deferred because OWL 2 DL forbids
those positions.

Atomic complements participate in composite class-domain remapping without manufacturing
entity bindings for non-entity expressions. Each referenced named concept has paired positive
and negated predicates, a builtin clash clause, and a builtin `owl:Thing` totality disjunction.
Signed subclass literals preserve scalar provenance, composite remapping, and the scalar JSON
lexical ordering of multi-digit predicate identifiers. Scalar-trivial complement inclusions reduce
without leaking expression symbols. Atomic equivalence cycles retain the same signed edges and
grouped provenance as scalar, including composite remapping. Atomic disjointness members retain
their signed guard chain, canonical guard identity, annotated provenance, top/bottom reductions,
and composite remapping. Signed object-property domain/range, data-property domain, and key class
literals preserve exact constraint clauses, provenance grouping, and composite remapping.
Complements of `owl:Thing` and `owl:Nothing` normalize to the opposite builtin without expression
symbol leaks. Nested complements over supported named classes and named-individual nominals reduce
by parity to the base literal or innermost signed expression under bounded depth and work. The
normalized signed expression also supplies disjoint-guard identity, so guard hashes remain exact
across scalar comparison and composite remapping. Partially supported inclusions, equivalences,
disjointness and constraint roots, complements with complex bases, and other unsupported class
constructors remain wholly deferred without leaking partial symbols, predicates, clauses, or facts.

Atomic enumerations and datatype restrictions participate in exact composite remapping without
acquiring datatype entity bindings. Arbitrarily nested data complements over supported named,
enumerated, or restricted ranges reduce by parity under bounded depth and work. Positive and
negated data-range predicates receive builtin clash clauses and `rdfs:Literal`-guarded totality
disjunctions in the data sort. Annotated data-property ranges and datatype definitions preserve
scalar provenance and canonical ordering. The empty `DataComplementOf(rdfs:Literal)` range is also
exact. Data complements with unsupported complex bases remain wholly deferred without leaking
symbols, predicates, or clauses.

Flat `DataIntersectionOf` and `DataUnionOf` expressions in `DataPropertyRange` now cross the
generated-definition boundary when every child is a named datatype, `DataOneOf`,
`DatatypeRestriction`, or one direct complement of those atomic forms. The native compiler hashes
the canonical data expression with the scalar normalization-definition domain and the full ontology
logical fingerprint, publishes the generated datatype in both entity and data-range domains, and
retains the source Boolean expression for scalar predicate ordering. Positive intersections emit
one generated-to-operand data-sort clause per member; positive unions emit the corresponding
generated-to-disjunction clause. The property-range clause then targets that generated datatype.
Annotated duplicate roots reuse the same identity and merge provenance, while composite slices
remap the generated datatype, source entities, predicates, clauses, and provenance through the
global domains. Top/bottom, duplicate-normalized, nested, or partially unsupported expressions
remain fail-closed and publish no partial generated state.

Flat multi-live Boolean `DatatypeDefinition` right-hand sides use the same supported atomic operand
boundary but do not create a generated datatype: scalar normalization retains the source Boolean
symbol only for canonical domain ordering and directly expands the named-datatype equivalence.
Intersections emit named-to-member clauses plus one member-conjunction-to-named clause; unions emit
the dual named-to-disjunction clause plus one member-to-named clause per operand. Signed operands,
tautology elimination, provenance grouping, and composite remapping follow the same data-sort clause
pipeline as generated range definitions. Unsupported nested right-hand sides still defer wholly.

Complement chains around a supported flat data Boolean are traversed under the canonical depth and
work budgets. Odd parity swaps intersection/union and complements each atomic member; even parity
removes the wrappers. The native compiler constructs the normalized canonical Boolean and
complement keys without materializing Python objects, so direct and De Morgan-equivalent source
forms reuse the same scalar generated definition in composite views. `DataPropertyRange` and
`DatatypeDefinition` then follow their respective generated or direct-equivalence paths. A nested
Boolean operand or another unsupported child still rolls back the complete root without publishing
synthetic symbols, predicates, clauses, or provenance.

Homogeneous nested intersections and unions are recursively flattened after complement parity is
applied at each level. This produces the same scalar n-ary canonical key and clause set as an
already-flat source expression, including direct, De Morgan-equivalent, and composite forms.
Traversal is bounded by canonical depth, symbol count, work, and owned-byte limits. For
`DataPropertyRange`, mixed nested connectives recursively create the scalar inner definitions,
rewrite their parent operands to generated datatype entities, and then create the parent definition
from its original normalized identity. This preserves both the source and rewritten expression
symbols, dependency clauses, annotated provenance reuse, deep branching, and composite global
namespacing. Mixed nested `DatatypeDefinition` right-hand sides remain outside this checkpoint and
defer atomically because the scalar compiler does not currently expose a stable compiled contract
for that form.

Named-individual object nominals retain canonical `ObjectOneOf` expression symbols and `Nominal`
predicates annotated by the remapped individual IDs. Their scalar-equivalent clauses define
membership through object equality; atomic complemented nominals additionally receive a
`NegatedNominal` predicate, object-inequality consequences, and the ordinary complement
totality/clash clauses. Assertions, subclass inclusions, equivalences, disjointness, object-property
domains/ranges, data-property domains, and keys share the same signed literal mapping. Annotated
duplicate roots preserve provenance, slice composition remaps both class and individual
identifiers. Tautological roots reduce, nested complements over named nominals normalize by parity,
and anonymous-member or partially supported roots defer without leaking nominal symbols or
predicates.

`ObjectIntersectionOf`, `ObjectUnionOf`, `DataIntersectionOf`, and `DataUnionOf` recursively remove
their top/bottom identity members, honor absorbing members, reduce complement parity, and collapse
normalized duplicates when the result is a single supported literal or builtin. No Boolean wrapper
symbol is published for these scalar-reduced roots. Disjoint members are re-sorted by their
normalized canonical keys before guard hashing; duplicate normalized members produce the scalar
forced-empty inclusion rather than a spurious guard. Absorbing members do not short-circuit input
validation: later unsupported operands force whole-root deferral before any symbol or predicate is
published. Multi-live expressions are admitted only through the generated-definition positions
described below; restriction-bearing or otherwise unsupported forms remain atomically deferred.

`ObjectSomeValuesFrom` and `DataSomeValuesFrom` reduce over empty fillers;
`ObjectAllValuesFrom` and `DataAllValuesFrom` reduce over universal fillers. Zero minimum
cardinalities and minimum/maximum/exact cardinalities over empty fillers reduce to the corresponding
builtin class, including nested complement and Boolean positions and composite slice remapping.
Restriction inputs are traversed under the canonical depth/work budgets before publication.
Undeclared entities, literals, anonymous individuals, and top/bottom property symbols that scalar
normalization would prune make the entire root defer, avoiding dead-domain identifier drift.
When the builtin bottom properties are explicitly declared, their retained identities are allowed:
object existential, universal, and value restrictions and data existential, universal, minimum,
maximum, and exact cardinalities still reduce to their scalar builtin result.
Syntactically distinct restrictions that reduce to the same builtin share that builtin's normalized
disjoint key, so duplicate members force the scalar-equivalent empty-class inclusion.
General restrictions that require generated definitions remain outside this checkpoint.

`DisjointUnion` roots reuse the same normalized literal keys as ordinary disjoint-class axioms.
Reducible unions preserve annotated source provenance, emit the defined-to-union and
member-to-defined edges, apply duplicate/top/bottom disjoint normalization, and remap composite
slices exactly without a generated symbol. A union with multiple supported members builds the
canonical `ObjectUnionOf` bytes directly, publishes the scalar-identical positive generated outer
definition, and emits the same definition edges and disjoint guard. Recursive Boolean members
receive negative definitions for their member-to-defined and disjoint uses; the outer union rewrite
recursively creates the corresponding positive definitions. Homogeneous member unions flatten into
the outer identity. These definitions are shared with materialized expressions, annotated aliases,
and composite slices under the global logical fingerprint. Restriction-bearing unions still defer
without publishing partial symbols, predicates, clauses, or provenance.

Multi-live class Booleans in `SubClassOf`, `EquivalentClasses`, `ClassAssertion`, object-property
domains/ranges, data-property domains, key class expressions, and disjoint-class members now cross
that generated-definition boundary when every leaf is a named class, atomic complement, or
named-individual nominal. Homogeneous nesting is flattened after complement parity and De Morgan
normalization; mixed nesting is recursively replaced by generated inner classes with the same
polarity as the owning definition. The native compiler uses the full
ontology logical fingerprint for generated IRI namespacing, hashes the canonical expression bytes
with the scalar normalization-definition domain, and inserts generated class entities before
remapping the source
class and individual signatures. Positive intersections and negative unions emit directional
definition edges; negative intersections and positive unions emit the corresponding
conjunctive/disjunctive clauses. Equivalence members allocate and reuse both polarities around the
canonical scalar cycle. Class assertions reuse the positive definition and emit the exact fact for
named or anonymous individuals. Property constraints reuse the positive definition and preserve
forward/inverse object roles or data roles. Keys reuse the negative definition and preserve mixed
object/data role sets plus ordering-guard clauses. Disjointness reuses the negative definition and
hashes/sorts guards by the generated class key, including scalar top/bottom reductions. Generated
disjoint unions reuse the positive union definition before adding their exact definition edges and
guard. Direct, De Morgan-equivalent, deeply nested, and composite forms preserve both the source
and generated-child-rewritten expression symbols, generated provenance, scope/identifier remapping,
and deduplicate annotated and cross-root uses exactly. A partially unsupported root rolls back
without generated symbol leaks. Recursive restriction definitions remain atomically deferred.

`ObjectHasSelf` expressions now use the same polarity-specific generated class identity as the
scalar normalizer. Positive definitions emit the repeated-variable implication from the generated
class to the object role, while negative definitions emit the reverse implication. Complement
parity flips the inner definition polarity and publishes the exact signed generated-class alias;
recursive class Booleans atomize self restrictions as dependency definitions. Subclass antecedents
and consequents, equivalence members, class assertions, object-property domains/ranges,
data-property domains, keys, disjoint-class members, and generated disjoint unions reuse those
definitions with exact source/generated provenance grouping. Inverse roles, annotated duplicate
roots, and composite slices preserve the canonical expression and global logical-fingerprint
namespace. Unsupported sibling expressions still roll back the entire root without publishing an
`ObjectHasSelf` symbol.

Object quantifiers now use the scalar canonical restriction identity and generated class namespace
in every definition polarity. A negative `ObjectSomeValuesFrom(R, F)` definition emits
`R(x, y) ∧ F(y) -> G(x)`; a positive `ObjectAllValuesFrom(R, F)` definition emits
`G(x) ∧ R(x, y) -> F(y)`. The relational atoms pass through the ordinary scalar-predicate
canonicalizer and key-join planner, so clause keys, atom order, variable numbering, and join order
match scalar output. A positive `ObjectSomeValuesFrom(R, F)` definition emits
`G(x) -> AtLeastObject(1, R, F)(x)`. A negative `ObjectAllValuesFrom(R, F)` definition emits
`owl:Thing(x) -> AtLeastObject(1, R, not F)(x) or G(x)`. The native predicate registry derives the
same scalar key from the role, cardinality, and canonical signed filler predicate, retains the
runtime role predicate, and remaps filler predicate identifiers after global ordering. Outer
complements normalize by quantifier duality and complement the filler, allowing direct and dual
source forms to reuse one generated definition. Recursive class Booleans can own these definitions
in subclass, assertion, property-domain, key, disjointness, and generated disjoint-union positions.
A complex filler is atomized with the owning definition polarity before the outer quantifier is
rewritten, producing dependency-ordered Boolean, self, or nested-quantifier definitions and both
the source and rewritten restriction symbols. Inverse roles, positive and negative nominal fillers,
annotated aliases, global composite namespacing, and provenance merging remain exact. Unsupported
sibling constructors still preflight transactionally and roll back the complete root without
leaking restriction identities, roles, predicates, clauses, or generated provenance.

## Open acceptance boundary

WP18 remains open. Remaining complex class-expression and data-range normalization/clausification,
complete root/profile/error coverage, direct permanent-session publication, cancellation
and allocation-failure campaigns, the full forced-native/verify matrix, installed
artifacts, and controlled performance/RSS gates are not yet complete. No public
capability or performance claim is justified until the complete work-package acceptance
matrix passes.
